The plan is worked out from estimates until the owner measures the real thing. Each input below lives in
`data/measurements.yaml`, which can be edited in GitHub's web editor. Put the measured value and the date in its
`measured` slot, and the push to main rebuilds this site with the plan re-solved from it.

Each input has rules that change the plan, not only a warning. For example, the Tuareg's measured width at the
Street Triple's bar end sets the bike spacing, and the garage, the body layout and the axle position follow. The
towball target is the highest load that keeps the car's rear axle within 1,600 kg with the planned gear in the car,
capped at the 280 kg towball rating. These rules are design rules with their source. They never change a check's
limit.
