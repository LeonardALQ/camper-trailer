The drawings are generated from the same 3D model and data as the rest of the site. Each sheet is A3 in third-angle
projection, and every dimension is in millimetres. Each one has a title block, a revision table and a parts list.

All four sheets are drafts, and the table below gives each one's current revision. On a sheet, a revision
cloud and a small triangle with the revision letter mark what changed in that revision. Nobody has checked or
approved the drawings yet, and the engineer has not reviewed them, so do not build from them. A sheet can only
go to the shed once its status is FOR CONSTRUCTION.
